# Content library

Open Library from App home. Search the content your current native account can open; certified metrics rank first. Collections, tags and private favourites narrow the search. A collection grant exposes folder metadata; individual item grants independently control item metadata. Neither grants source rows or query execution. Private names are excluded from results, suggestions and counts.

An owner registers dashboards, reports, questions, notebooks, metrics and source columns under Library settings. Definitions and human verification remain versioned. A certified metric requires an executable typed native query; a badge cannot authorize source execution. Source links are explicit local paths or HTTPS addresses without credentials, query strings or fragments.

Owner controls on an item expose current reader grants, metadata, dependencies, version history and reversible archive. Review the exact current version and dependency fingerprint, then explicitly approve archive or restore. Stale approval fails. Archive removes ordinary discovery while retained links explain the state. It preserves favourites, source links, versions and historical usage. Restoring an installation never activates archived grant definitions; the owner must activate them against current membership.

## Usage privacy

The ct ruling of 23 October 2026 at 09:50 UTC governs this flow. Collection is off until audited owner consent names the collected event id, content item id, reader id, tenant and opened time. Earlier unnamed consent must be renewed. Settings binds approval to the current disclosure and policy version. Withdrawal stops new imports immediately; retained usage follows installation retention and explicit source erasure. There is no automatic destructive action or agent mutation.

Import an authorized JSON file with an events array under Settings. Review its actual events and approve before importing. Every event must refer to existing content and an active, currently permitted reader, carry a unique id, and fall within the prior ninety days. Exact duplicate delivery is idempotent; a reused id with different content fails.

Hygiene marks stale, unused and duplicate content, with owner and dependency context. Aggregate usage is shown only for items meeting the minimum distinct-reader cohort of five; suppressed groups expose no aggregate count or last-open timestamp. Identifiable reader and tenant detail and historical denominators remain expressly owner-only. Archive and restore preserve adoption denominators. Source erasure removes controlled content, usage, search entries and retained derivatives.

The existing content-governance journey proves native invited-reader access, source custody and the complete library route at desktop and phone widths. Its browser and cohort helpers exercise explicit consent, actual reviewed usage-file import, small-group suppression, an authorized complete cohort, reversible archive and immediate withdrawal.
