# Tableau source packages and Pulse drafts

The installed `/app/import` page accepts owner-supplied TDSX packages, textual TDS definitions and original Pulse JSON responses. This is bounded native intake, not a live Tableau connector or completed migration. No connection is fetched, no Hyper engine runs, and imported ownership, permissions, certification, refresh settings, thresholds and followers confer no authority.

Supply the original published-source ID and exact TDS path, including the package filename. The package inventory records every entry, its expanded byte count and SHA-256. Extracts and unsupported entries remain visible. Definition metadata retains source and site IDs, API and schema versions, original filenames, source expressions, dependency links and the supplied cutoff. Missing definitions, unresolved security and dependencies, unsupported executable semantics and incomplete follower pages prevent native previews. Missing ownership, refresh and follower evidence remains diagnostic. Archives are bounded to 64 entries and 4 MiB expanded, with each entry at most 1 MiB and each TDS at most 256 KiB; paths never reach the filesystem. The complete door upload is at most 1 MiB. DTDs, entities and credential-bearing content are refused. Refused credential uploads are removed by the shared door; diagnostics contain no credential values.

Pulse JSON uses the original `GetDefinitionResponse`, `GetMetricResponse` and `ListSubscriptionsResponse` shapes. The supported definition and metric schema version is `1.0.0`. Definitions preserve metadata, specifications and inactive display, certification and threshold references. Metrics preserve their stable IDs, definition links, versions, equality filters and measurement periods. Subscriptions preserve each user or group reference separately. A supplied response never establishes complete authorized REST enumeration or provider-grant revocation.

For native previews, map each source metric ID to a separately reviewed native dataset ID and its exact revision, an explicit physical field map, unique row grain, timezone and native query context. Only single-source scalar SUM and count-distinct of physical fields are translated. Equality filters use one categorical string, boolean or null value; instance filters must be declared filterable by the definition. The original metric must supply a fixed specific-period date and end date with `RANGE_BY_CONFIG`. Relative dates, running totals, advanced filters, calculated measures, comparisons and unresolved source semantics remain gaps. USD sums use the original declared currency and decimal places. The reviewed native calendar, accounting basis, timezone, source revision and current owner are rechecked by the native metric handlers.

Review the inventory, Apply and reconcile it through the shared door. Native metric previews show the complete draft document and exact value. Saving requires a second exact review bound to the project revision, metric revision and current source evidence. The result is an uncertified native draft; certification remains a separate explicit current-human operation. No imported follower is subscribed and no schedule sends. Undo remains available before native drafts are created; later native work requires explicit reviewed erasure instead of an unsafe rollback. Eligible project or source erasure withdraws retained originals, history and linked drafts, permanently retiring the project ID. Legal holds and minimum source retention prevent that erasure. Complete archive restoration and provider-retained-copy qualification remain unfinished.
